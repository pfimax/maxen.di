# API reference

Every public type and member of the Maxen.DI libraries, generated from the XML comments in the source.

- `Maxen.DI`: the container, the builder, lifetimes, attributes and the everyday extension methods.
- `Maxen.DI.Extensions.DependencyInjection`: Maxen.DI behind `IServiceCollection` and the Generic Host.
- `Maxen.DI.Extensions.AspNetCore`: `UseMaxenDI`, request values and the diagnostics endpoint.
