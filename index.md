# Maxen.DI

A dependency injection container for .NET that tells you what is wrong before your users do. It checks your wiring as you
type, at startup and in CI, then resolves quickly and stays open to change.

- [Getting started](docs/getting-started.md): register services, resolve them, use scopes.
- [Extending](docs/extending.md): middleware, lifetimes, sources, interception and diagnostics.
- [Migrating](docs/migrating.md): the Microsoft DI and Autofac calls and what they become here.
- [Diagnostics](docs/diagnostics.md): what each MAXEN warning means and how to fix it.
- [Comparison](docs/comparison.md): features and speed next to Microsoft DI and Autofac, with the tests that back each claim.
- [API reference](api/index.md): every public type and member, generated from the XML comments.
